# Fonts

The window's toolbar is set in Inter, Living Tool's UI face.

`Inter-Regular.ttf` (weight 400) and `Inter-Medium.ttf` (550) are static instances of the Latin subset of Inter 4.001 that the films use (`web/video/shared/fonts/inter.woff2`), made with fontTools' `varLib.instancer`.
